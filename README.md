Nuestro proyecto consistirá en crear una página web para una biblioteca (la de la escuela), con el objetivo de mejorar la organización de los libros y facilitar su uso dentro y fuera de la escuela.
La página estaría pensada para que alumnos, docentes y la bibliotecaria puedan ver qué libros hay disponibles, registrar préstamos y devoluciones, y tener un mejor control de todo el material. De esta manera, se evitarían desórdenes, pérdidas o errores que suelen ocurrir cuando todo se anota de forma manual.
Hoy en día, una página web para este tipo de tareas puede facilitar mucho el trabajo, además de permitir tener toda la información ordenada y accesible.
En este trabajo también explicaré la idea del proyecto, sus funciones principales, las herramientas que se usarán para desarrollarlo y cómo podría ayudar al funcionamiento de la biblioteca.
Este proyecto aspira a aportar una solución práctica y útil para mejorar la organización de la biblioteca mediante una página sencilla
