Volver al inicio

  • Objetivo general: Diseñar e implementar un sistema web que automatice la gestión de préstamos, devoluciones e inventario de la biblioteca escolar.
  • Objetivos especificos:
    1. Crear una base de datos con el catálogo completo de libros (título, autor, categoría, stock).
    2. Automatizar el registro de préstamos para reducir errores humanos en las fechas de entrega.
    3. Facilitar a los alumnos un buscador rápido para verificar la disponibilidad de libros desde cualquier dispositivo
